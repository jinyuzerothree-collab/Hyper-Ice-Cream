# Hyper Ice Cream v2.1

## 新增

- **关于页 1:1 重构**（对标 HyperCeiler）：渐变 Hero（图标 + Hyper Ice Cream + 版本 | release）→ 设备信息卡片（"用户名 的 设备名"大字 + 型号/Android/OS 版本）→ 开发者卡片（头像 + GitHub）→ 贡献者/官方网站/翻译/支持 → 用户协议/隐私政策 → 译者
- **应用内三语切换**（关于页）：简体中文 / 繁體中文 / English，即时生效
- **开发者头像**接入关于页
- **小组件尺寸自选**：部署时钟/天气/便签等组件时，逐个弹窗选择宽 × 高（桌面格数 1–6，默认按组件名比例）——所选尺寸直接写入组件声明，不再依赖桌面手动调整

## 变更

- **图标重绘**：巧克力雪糕 + 深空科技底 + 青色点缀（替换粉底白糕像素版）
- **移除顶部标题栏**：去掉黑色标题条，页面更沉浸
- **Dock 左右滑动切页**：四页支持横向滑动手势（与点击并存）
- **Dock 激活态改为液态玻璃同材质覆盖层**：半透明亮/暗一层，替代实色 accent 大色块

## 已知问题

- 系统级背景模糊在本 ROM 不可用（运行时缺字段），Dock 玻璃为半透明+高光模拟
- 小组件缩放手柄仍待验证（Plan A 注入修复）；如 Launcher 拒绝，请使用 Hyper Ice Cream Widget（Plan B，尺寸自由）
- 关于页用户名默认"Ache"，暂未提供修改入口
