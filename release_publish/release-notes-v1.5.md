# HyperOS-Theme-Installer v1.5

## 修复

- **小组件缩放失效（根因修复）**: 部署时自动为缺失描述文件的组件容器注入标准尺寸声明（category/size 从组件名解析），修复 Launcher 将主题小组件识别为固定尺寸的问题。平板端添加小组件后应可长按拖拽调整大小。
- **社区下载全程无反馈**: 新增下载任务管理器——进度条、百分比、实时速度、直连/镜像自动切换、三阶段状态（下载/SHA256校验/完成）、失败原因明示。
- **社区主题重复贡献**: 社区下载的主题部署后不再弹贡献提示，仅本地导入主题提供贡献入口。

## UI 重构

- 三页面架构（部署 / 社区 / 工具）+ Liquid Glass 悬浮底栏（悬浮留白、大圆角、半透明玻璃、高光、阴影、点击缩放动画）
- Material You 动态取色：底栏激活色跟随壁纸主色，日夜模式自适应
- 社区列表卡片圆角化、统一间距

## 已知问题

- 小组件缩放手柄的最终目视确认待用户验证（根因修复已按出厂对照实锤：出厂组件均带 size 声明，第三方简化格式缺失导致降级）
- 动态取色为简化实现（壁纸主色单色 accent），非完整 Monet 色板
- themes/index.json 中样例条目的下载/预览链接待首批主题入库后回填

## 注意事项

- 需要 Root（su 授权）与「所有文件访问」权限
- 每次部署前自动备份到 /sdcard/ThemeToolBackup/
- 详细技术报告见仓库 REFACTOR_REPORT.md
