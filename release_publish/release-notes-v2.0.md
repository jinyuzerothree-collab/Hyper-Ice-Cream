# Hyper Ice Cream v2.0

> HyperOS 平板主题增强工具（原 HyperOS-Theme-Installer / 主题直装）

## 品牌更新

- 项目更名 **Hyper Ice Cream**，全新像素风白雪糕图标
- UI 全面重构：部署 / 社区 / 工具 / 关于 四页面 + 液态玻璃悬浮底栏 + 壁纸主色动态取色

## 新增

- **Hyper Ice Cream Widget**：独立于 MIUI Gadget 体系的时钟桌面小组件——桌面内自由缩放（2×1 起步），按尺寸自动重排版（非拉伸）；部署主题时钟后自动复用主题数字贴图
- **Gadget 缩放根因修复**：部署时自动为缺失描述文件的组件容器注入标准尺寸声明（从组件名解析 W:H），修复平板端主题组件被固定为 2×1 无法缩放的问题
- **关于页**：设备信息卡片、开发者信息、更新日志/许可/收录规范/Issues 快捷入口
- **下载任务管理器**：社区下载进度条/百分比/速度/镜像自动切换/SHA256 校验/三阶段状态
- **贡献去重**：社区主题（路径 + sha256 双重比对）不再重复贡献；本地修改过的主题仍可贡献

## 已知问题

- HyperOS 4 运行时缺窗口级背景模糊字段（实测），底栏玻璃为半透明+高光模拟；真模糊待 Compose 迁移评估
- 小组件缩放手柄的最终目视确认待回归（根因修复已部署）
- 社区索引当前为样例条目，下载全流程待首批主题入库后回归

## 注意事项

- 需要 Root（su 授权）与「所有文件访问」权限
- 每次部署前自动备份到 /sdcard/ThemeToolBackup/
