# 主题直装 工具功能报告

**版本**: v1.2 (versionCode 3)　**包名**: com.zcode.themetool　**体积**: ~29KB
**平台**: Xiaomi Pad 8 Pro / HyperOS 4.0.0.31 (Android 17)
**权限模型**: Root (KernelSU su) + 所有文件访问；无需 LSPosed、无联网权限、无广告

---

## 一、功能总览

| 功能 | 说明 |
|---|---|
| 主题包识别 | 支持 .mtz 主题包、.zip 包、已解包目录、单组件文件（自动识别格式并解包） |
| 组件勾选部署 | 识别出的每个组件独立勾选，只应用用户选中的部分 |
| 自动备份 | 每次部署前自动把当前整套主题备份到 `/sdcard/ThemeToolBackup/backup_<时间戳>/` |
| 一键还原 | 从最近一次备份还原全部组件 |
| 重启系统界面 | 一键 `am crash` 重启 SystemUI，刷新状态栏/电池图标等组件 |
| 内置文件浏览器 | 只显示 mtz/zip/ttf（可切换显示全部），目录导航，替代 HyperOS 捆绑选择器 |

## 二、支持的组件

| 组件 | 覆盖内容 | 部署位置 | 状态 |
|---|---|---|---|
| 状态栏 / 电池图标 | 状态栏资源、电池图标全套（含暗色模式） | `/data/system/theme/com.android.systemui` | ✅ 验证可用 |
| 系统图标 / 桌面图标 | 桌面图标包、系统图标替换 | `/data/system/theme/icons` | ✅ 引擎原生支持 |
| 壁纸 | 静态壁纸 | `/data/system/theme/wallpaper` | ✅ 验证可用 |
| 锁屏壁纸 | 锁屏壁纸图 | `/data/system/theme/lock_wallpaper` | ✅ 验证可用 |
| 字体 | 主题包 `fonts/` 内的 ttf/otf | `/data/system/theme/fonts/` | ⚠️ 实验性（引擎支持未验证，部署后需重启设备） |

**部署原理**：HyperOS 主题引擎在运行时从 `/data/system/theme/` 读取已部署组件（优先级高于默认主题）。本工具将主题包内对应组件以引擎期望的格式与属主（system_theme:system_theme）直接写入该目录并重启 SystemUI，等效于"免审核直装"。

## 三、使用流程

1. 首次使用：点「授权所有文件访问」（系统设置页，授权一次即可）
2. 点「① 选择主题包 / 字体文件」→ 内置浏览器（只显示 mtz/zip/ttf）→ 选择文件
3. 工具自动解包并列出组件 → 勾选要应用的部分
4. 点「② 部署到系统主题」→ 自动备份 → 写入 → SystemUI 自动重启
5. 壁纸若未立即变化，重启设备一次

**还原**：任何时候点「还原最近一次备份」即回到部署前状态；备份目录同时保留在 `/sdcard/ThemeToolBackup/` 与电脑端。

## 四、已知限制

1. **字体为实验性**：OS4 引擎对 `/data/system/theme/fonts` 的读取未获官方确认，无效时无副作用
2. **框架级全局主题不可用**：涉及 framework-res 注入的深度主题（如状态栏布局重构）需要主题商店通道，本工具不涉及
3. **mtz 内以下组件不会部署**：maml 动画、动态壁纸、音效（引擎对普通应用部署这些组件的支持有限，已自动跳过并列出）
4. 每月 OTA 更新后 `/data/system/theme` 内容不受影响（该目录在 data 分区），无需重新部署

## 五、故障与恢复

| 情况 | 处理 |
|---|---|
| 部署后 SystemUI 异常 | 点「还原最近一次备份」→「重启系统界面」 |
| 备份目录损坏 | `/sdcard/ThemeToolBackup/` 按时间戳手动选择更早的备份 |
| 工具本身卸载 | 卸载 App 不影响已部署主题；删除对应文件即回到默认 |

## 六、版本历史
